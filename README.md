# Stargazing intro

山顶看星星的开场动画：一层层出现。一个 HTML 文件，没有依赖，手机竖屏优先。

**黑 → 星空浮出来、往后退一点 → 满天小星 → 两颗亮星依次亮起 → 山顶营地从下面浮上来 → 小人落下 → 标题、第一颗流星**

开场大约 2.6 秒，之后星星一直闪、流星隔几秒从右上划到左下、篝火在跳、火星往上飘。

- 点一下屏幕：跳过开场，直接到结尾
- 系统开了「减少动画」：不播开场，也不闪

## 用

把整个文件夹放到任何静态服务器上，打开 `index.html` 就行。本地看可以：

```sh
python3 -m http.server 8000
# 打开 http://localhost:8000
```

> 直接双击用 `file://` 打开也能看，但有的浏览器不让 canvas 读本地图片，最好起个服务器。

## 改

所有能调的都在 `index.html` 里的 `CONFIG`：

| 项 | 管什么 |
|---|---|
| `ground` | 营地图：路径、原始尺寸、放大多少、往左挪多少、像素格多大、火在图里哪儿、火星从哪儿飘 |
| `sprites` | 放在地上的小人（可选），每个一张像素图 |
| `sky` | 散星、银河的密度，会闪的星有几颗 |
| `bright` | 两颗亮星的位置、大小、颜色 |
| `meteor` | 流星隔多久一颗、两颗前后脚的概率 |
| `intro` | 开场时间线：每一层在第几毫秒出现 |

### 换营地图

- 用 **天空是透明的** PNG / WebP，贴着屏幕底边放。图越宽越清楚（1024 宽就够）。
- 图会在手机上现场按「每格整数个物理像素」重画一遍，所以任何屏幕上边缘都是硬的、不糊。想更像素风就把 `cellCss` 调大。
- `fire` 填火在图里的位置（占图宽 / 图高的比例），那一块会被复制出来做跳动；图里没有火就设成 `null`。

### 加小人

把像素图放进 `assets/`，在 `sprites.list` 里加一行：

```js
sprites: { x: 0.495, bottom: 0.505, list: [
  { src: 'assets/me.png', w: 35, h: 22 },
  { src: 'assets/you.png', w: 31, h: 22 },
] },
```

`x` / `bottom` 是小人站在图上的哪儿（占图的比例）。开场时它们会从上面落下来弹一下，之后轻轻晃。

## 素材

- `assets/camp.webp`：山顶营地（帐篷、背包、篝火、望远镜），AI 生成后抠掉天空。跟代码一样按 MIT 随便用。
- 天空、星星、流星、亮星都是代码画的，没有图片。
- 标题用 Playfair Display 斜体，没装的话会退到 Georgia。
